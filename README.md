## Sobre

Sou formado em Análise e Desenvolvimento de Sistemas e atuo como desenvolvedor full stack freelance, criando sistemas para clientes reais de ponta a ponta: da interface e das APIs aos testes unitários e end-to-end, até a infraestrutura que coloca tudo no ar.

Gosto de entender o porquê das coisas. Meu foco está nas decisões de arquitetura: como os dados se organizam, como os sistemas se integram, como protegê-los e quais trade-offs de custo e manutenção fazem sentido em cada projeto. Uso IA para acelerar a implementação, mas as decisões técnicas, o desenho da solução e a revisão do que vai para produção continuam sob minha responsabilidade.
